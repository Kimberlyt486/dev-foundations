# Terminal Cheat Sheet


| `pwd` | Shows the folder I'm currently in (my location) 
| `ls` | Lists files or folders in the currect directory 
| `ls -la` | Lists hidden files and details in directory as well 
| `cd` | change directory
| `mkdir -p` | Make folders ( -p creates parent folder)
| `touch` | Creates an empty file 
| `cp` | copy file
| `mv` | move file
| `rm` | delete file
| `cat` | show a file
| `echo "text" >> file` | append text to a file
| `git clone` | clones a repo
| `code` | open vs code with new file
